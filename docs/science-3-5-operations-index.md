## Drive rules

- Keep staff source files in a staff-only folder.
- Publish PDF or view-only student copies; never give students edit rights to source files.
- Use one folder per lesson: `01-topic`, `02-topic`, and so on.
- Name files consistently: `S3-5_W01_topic_slides.pdf`, `..._worksheet.pdf`, `..._assessment.pdf`, and `..._family-note.pdf`.
- Add a resource only after the teacher approves the final version and confirms it contains no student data.
